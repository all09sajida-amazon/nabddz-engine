# نبض الجزائر - المحرك (Nabd Dz Engine) v2.0 🇩🇿

> المحرك البرمجي الذكي الذي يحول أي موقع ويب إلى كائن رقمي يتفاعل مع مشاعر زائره.

![Nabd Dz Engine Logo](https://upload.wikimedia.org/wikipedia/commons/7/77/Flag_of_Algeria.svg)

**نبض الجزائر - المحرك** هو مكتبة JavaScript خفيفة الوزنة وقوية. تم تصميمه ليتم دمجه بسهولة في أي مشروع ويب (بلوجر، ووردبريس، أو أي موقع مخصص) لإضافة ميزات تفاعلية ونفسية فريدة.

## ✨ ماذا يفعل المحرك؟

-   🧠 **تحليل المزاج:** يحلل سلوك تمرير المستخدم لتحديد حالته العاطفية (إيجابي، سلبي، محايد).
-   🎨 **واجهة ديناميكية:** يغير ألوان ومظهر الموقع بناءً على المزاج المستنتج.
-   ⚡ **نظام Gamification:** يحول تفاعل المستخدم إلى نقاط ومستويات طاقة (شرارة، تدفق، موجة، طاقة محركة).
-   🆔 **منشئ الهوية:** يوفر واجهة لإنشاء هوية رقمية شخصية.
-   💬 **شات بوت تفاعلي:** يوفر أساساً لإنشاء مساعد ذكي يتفاعل مع المستخدمين.
-   📊 **أرشيف المشاعر:** يسجل تاريخ المزاج ويعرضه في رسم بياني.

## 🚀 معاينة سريعة

يمكن رؤية المحرك في العمل ضمن قالب بلوجر **[نبض الجزائر](https://github.com/all09sajida-amazon/nabdz-el-djazair-blogger-template)**.

## 📦 كيفية التثبيت والاستخدام

### التثبيت عبر CDN (الأسهل)

أضف السطر التالي قبل وسم `</body>` في موقعك:

```html
<script src="https://cdn.jsdelivr.net/gh/your-username/nabddz-engine@latest/app.js"></script>
<script>
  window.addEventListener('DOMContentLoaded', () => {
    NabdzApp.init();
  });
</script>
