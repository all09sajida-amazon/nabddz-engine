# نبض الجزائر - المحرك (Nabd Dz Engine) v2.2 🇩🇿

المحرك البرمجي الذكي الذي يحول أي موقع ويب إلى كائن رقمي يتفاعل مع مشاعر زائره.

Nabd Dz Engine Logo

نبض الجزائر - المحرك هو مكتبة JavaScript نمطية (Modular) وقوية. تم تصميمه ليتم دمجه بسهولة في أي مشروع ويب (بلوجر، ووردبريس، أو أي موقع مخصص) لإضافة ميزات تفاعلية ونفسية فريدة.

✨ ماذا يفعل المحرك؟
🧠 تحليل المزاج: يحلل سلوك تمرير المستخدم لتحديد حالته العاطفية (إيجابي، سلبي، محايد).
🎨 واجهة ديناميكية: يغير ألوان ومظهر الموقع بناءً على المزاج المستنتج.
⚡ نظام Gamification: يحول تفاعل المستخدم إلى نقاط ومستويات طاقة (شرارة، تدفق، موجة، طاقة محركة).
🆔 منشئ الهوية: يوفر واجهة لإنشاء هوية رقمية شخصية.
💬 شات بوت تفاعلي: يوفر أساساً لإنشاء مساعد ذكي يتفاعل مع المستخدمين.
📊 أرشيف المشاعر: يسجل تاريخ المزاج ويعرضه في رسم بياني.
🚀 معاينة سريعة
يمكن رؤية المحرك في العمل ضمن قالب بلوجر نبض الجزائر.

📦 كيفية التثبيت والاستخدام (الطريقة النمطجية)
للحصول على أقصى قدرات المحرك، استخدم "البذرة الجينية" (Genesis Seed).
